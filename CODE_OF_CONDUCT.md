# Code of Conduct · 행동 규범

This project exists to help adults be gentle with four-year-olds. We hold ourselves to the same standard.

- Be kind and specific. Critique the work, never the person.
- Assume good faith across languages; many contributors write in a second language.
- No harassment, discrimination or personal attacks, anywhere the project is discussed.
- Protect children: never post real classroom photos, child names or any identifying data in issues, PRs or discussions, even blurred.

Maintainers may edit or remove content and block contributors who break these rules. Report concerns privately through the repository's security advisory form or to the maintainers listed in the repository profile.
